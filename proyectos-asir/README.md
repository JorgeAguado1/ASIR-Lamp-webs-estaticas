# Proyectos de ASIR: guía para incorporarlos

Esta carpeta prepara la estructura para documentar más prácticas de ASIR en el portfolio.
**Todavía no contiene ningún proyecto publicado.**

## Reglas
1. **Solo se publica lo demostrado.** Cada afirmación necesita una evidencia real: captura, salida de un comando o fichero de configuración. Lo que no se pueda demostrar se marca como *no demostrado*.
2. **Se separa siempre** lo que pedía el enunciado de lo que se hizo.
3. **Se anonimiza antes de subir:** contraseñas y claves, identificadores de máquina, direcciones MAC, direcciones IP de la red del centro, nombres de equipos o personas ajenas y metadatos de los documentos.
4. **Enunciados y exámenes:** no se publican ni se copian. Se resumen con palabras propias y, si la práctica fue un examen o es material del profesor, se consulta antes de publicar nada.
5. **Una carpeta por proyecto**, con su `README.md` basado en [`PLANTILLA.md`](PLANTILLA.md). Cuando esté revisado y aprobado, se añade su tarjeta en `portfolio/proyectos.html`, en la sección de proyectos académicos.
